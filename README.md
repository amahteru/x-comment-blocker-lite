# X(Twitter) Comment Blocker Lite

用于自动屏蔽 X (Twitter) 评论区垃圾信息与引流机器人的油猴脚本，支持移动端浏览器（如 Safari、Via）及桌面端免扩展环境。相较于原版没有UI界面，无拉黑，管理，查看功能，保留了基本的屏蔽与云词库逻辑
